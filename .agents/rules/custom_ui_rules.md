# STRICT CUSTOM UI MANDATE

Across all applications, websites, web portals, admin apps, and client interfaces:
1. **Dropdowns (STRICT):** ALWAYS build custom Select/Dropdown components (NEVER use raw `<select>` tags or native browser option popups).
2. **Calendar / Date Inputs (STRICT):** ALWAYS use custom styled calendar date pickers or popover widgets (NEVER use native `<input type="date">` or OS date dialogs).
3. **Time Inputs (STRICT):** ALWAYS use custom styled time pickers or clock widgets (NEVER use native `<input type="time">` or browser time dialogs).
4. **Zero Native Popups (STRICT):** Zero native browser input styles, popups, or OS default controls.
