# AcademyPro Athlete Command

A full-stack sports performance management platform for high school academies and rugby sports programs.

---

## 📁 Repository Structure

* **`academypro_app/`**: Flutter mobile application (iOS & Android).
* **`web_admin/`**: Web Administration & Roster Management Portal (Cloudflare Pages).
* **`worker/`**: Backend API & Database Services (Cloudflare Workers + Cloudflare D1 SQL + Cloudflare R2).
